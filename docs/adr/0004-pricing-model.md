# Pricing model redesign (Lemon Squeezy-style)

Replaced the flat `price`/`sale_price` columns on `plans` with a 1:1 `Price` record per Plan, mirroring Lemon Squeezy: `category` (`one_time`, `subscription`, `lead_magnet`, `pwyw`), `scheme` (`standard`, `package`, `volume`, `graduated`), setup fee, renewal/trial intervals, pwyw suggested/min prices, and usage aggregation for metered billing. The `sale` feature (`sale_price`/`sale_starts_at`/`sale_ends_at`, `Plan::effectivePriceUsd()`, the `onSale` factory state) was deleted outright — it complicated renewal and coupon math for little value in an MVP. All price math now flows through `PriceCalculator` (one seam), money stays in integer cents (`MoneyCast`), and `licenses_per_unit` was removed in favor of exactly one License key per purchased unit (plans only gate `has_license_keys` + activation limit + license length). Metered usage is billed manually at renewal per ADR-0002.
